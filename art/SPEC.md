# 棋子美术数据格式

三个来源（Claude / Codex / Claude Design）各出 5 套，共 15 套，放进同一个画廊页面对比挑选。
格式必须完全一致，否则没法并排比。

## 文件形式

每个来源一个 JS 文件，放在 `art/sets/`，例如 `art/sets/codex.js`：

```js
window.SPRITE_SETS = window.SPRITE_SETS || [];
window.SPRITE_SETS.push({ /* 第 1 套 */ });
window.SPRITE_SETS.push({ /* 第 2 套 */ });
// ... 共 5 套
```

## 一套的结构

```js
{
  id: 'codex-1',            // 全局唯一
  author: 'Codex',          // Claude | Codex | Claude Design
  name: '厚描边贴纸',        // 这套风格的名字，中文，四到六个字
  note: '一句话说这套风格靠什么立住',

  palette: {
    grassMine:    '#cfe4a0',  // 我方三行草地
    grassMineAlt: '#c3da91',  // 同上，交错格
    grassFoe:     '#f4aeae',  // 敌方三行草地
    grassFoeAlt:  '#eea1a1',
    earth:        '#d3945c',  // 河两侧的陆地
    earthAlt:     '#c88a51',
    water:        '#9ad4ef',  // 河
    trapBg:       '#f2c25a',  // 陷阱格底色
    denMineBg:    '#a9dc8e',  // 我方兽穴格底色
    denFoeBg:     '#f7c4c1',  // 敌方兽穴格底色
    boardEdge:    '#b98d5f',  // 棋盘外框

    borderMine:   '#3f8f36',  // 我方棋子边框
    borderFoe:    '#cf3a34',  // 敌方棋子边框
  },

  // 13 个 SVG 字符串。每个都必须是完整的 <svg viewBox="0 0 100 100">…</svg>
  sprites: {
    rat: '<svg …>', cat: '…', dog: '…', wolf: '…',
    leopard: '…', tiger: '…', lion: '…', elephant: '…',

```

## 硬约束（全部来源都必须遵守）

**尺寸。** 棋子 SVG 在真实游戏里最小渲染到 **41px**（52px 格子 × 0.9 × 0.88），最大 70px。
按 41px 设计，不是按 100px。

**笔画。** `viewBox` 是 `0 0 100 100`。任何 `stroke-width` **不得小于 4**
（4 单位在 41px 下约 1.6px）。外轮廓建议 5。`stroke-linecap` 和 `stroke-linejoin` 用 `round`。
能用填充形状表达的，不要用细线。

**安全区。** 主要内容留在 `x=10..88, y=8..84`。
**右下角 `x=68..100, y=68..100` 会被汉字压住**，关键识别特征不许放进去。

**禁止**：渐变、滤镜、`opacity` 小于 0.6 的装饰、阴影（阴影由 CSS 管）、
胡须、睫毛、眼睛高光、小于 5 单位的牙齿、任何小于 4 单位的线。

**八只动物必须靠轮廓区分，不能只靠颜色。** 色弱、灰度、低质量屏幕都会削弱颜色。
建议以耳朵形状为第一识别特征：

| 动物 | 建议的第一特征 |
|---|---|
| 鼠 | 两个最大的圆耳 |
| 猫 | 短三角耳 |
| 犬 | 向下垂的长耳 |
| 狼 | 最高最窄的尖耳 |
| 豹 | 小圆耳 + 三个大圆斑（斑点直径 ≥ 7） |
| 虎 | 圆耳宽脸 + 额头三条粗纹（纹宽 ≥ 5） |
| 狮 | 一圈鬃毛剪影 |
| 象 | 横向最大的耳朵 + 一根粗鼻子 |

这是建议不是命令——如果你的风格有更好的区分办法，用你的，但**必须能通过纯黑剪影测试**：
去掉颜色和花纹缩到 24px，鼠猫犬狼狮象仍要大致可分。

**一套之内必须是一套。** 同样的眼睛画法、同样的描边语言、同样的色彩复杂度、
同样的取景（八只动物要么全是正面头像，要么全是全身，不许混）。

**五套之间必须明显不同。** 不是换配色，是换画法——剪影、厚描边、几何拼块、
纸艺分层、粗线描绘等等，随你。一眼要能看出不是同一套。

**地形四件（鳄鱼/荷花/陷阱/兽穴）要在自己的实际底色上好看**，
不是在白底上好看。鳄鱼在水上，陷阱在金色格上，兽穴在淡绿/淡粉格上。

## 目标用户

一个 6 岁小孩。幼态特征有研究支撑：大而圆的头、大眼睛、小鼻小嘴、眼距宽、眼睛位置偏低。
圆形没有尖角，不产生威胁感。

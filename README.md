# 斗兽棋 · 教学与陪玩

给 6 岁孩子的斗兽棋。纯静态网页，双击 `index.html` 就能玩，不装东西、不连网、不用开服务器。

## 给孩子的 Windows 电脑用

1. 把整个 `jungle-chess` 文件夹拷到那台电脑上（U 盘或局域网都行）
2. 右键 `index.html` → 打开方式 → Chrome 或 Edge
3. 在浏览器地址栏拖一下，或右键 `index.html` → 发送到 → 桌面快捷方式

孩子只需要双击桌面上那个图标。iMac 关不关机都不影响。

**第一次打开必须点一下「开始」按钮**——浏览器不允许网页在没人点过之前发出声音，那个按钮就是用来解锁语音的。

## 语音

现在用的是浏览器自带的中文发音，能用但机械。要换成好听的声音：

```bash
node tools/extract-voice-lines.js > voice-lines.tsv   # 55 条文案
```

把每一行用任意 TTS 生成，按 `key` 命名存成 `audio/<key>.mp3`。程序会自动优先播 mp3，找不到才退回浏览器发音——不用改任何代码，也不用一次做完，做几条就先用几条。

## 开发

```bash
node --test test/engine.test.js test/ai.test.js test/lessons.test.js
```

37 个测试，零依赖，不需要 npm install。

| 文件 | 作用 |
|---|---|
| `engine.js` | 规则引擎。所有走子、吃子、胜负判定 |
| `ai.js` | 三档难度的电脑对手 |
| `lessons.js` | 6 关教学的局面和全部语音文案 |
| `sprites.js` | 全部卡通图案（8 只动物、鳄鱼、陷阱、兽穴、荷叶），内联 SVG |
| `speech.js` | 语音播放，mp3 优先，浏览器发音兜底 |
| `index.html` | 界面和交互 |

三个文件都是普通 `<script>`，不是 ES module，也不用 `fetch` 读任何文件——这是为了在 `file://` 下能直接双击打开。加功能时请保持这一点。

## 采用的规则

象 > 狮 > 虎 > 豹 > 狼 > 犬 > 猫 > 鼠，鼠可吃象（反过来不行）。

**同级同归于尽**：一样大的两个碰在一起，两个一起消失，谁也不占那格。
只有双方都是满战力时才会同归。

**陷阱里的不同归**：一个棋子踩进对方家门口的陷阱，它自己的战力变 0。陷阱主人的
任何一个棋子都能把它吃掉，吃它的那个活着并占住那格——即使两边本来一样大。
站在自己家陷阱里不受影响，同级照样同归。

用最后一个子去同归，等于把胜利让给对方；双方同时打光，算平局。

**河里有两只固定的鳄鱼**，在 `(1,4)` 和 `(5,4)`。它们是地形不是棋子：不属于任何一方、
不能被吃、谁都不能停在那格。老鼠游不过去，必须绕开；狮子和老虎跳河时从它上面飞过，不受影响。

只有鼠能入水；河中的鼠和岸上的棋子互不能吃；河中的鼠之间相遇则同归于尽。
狮虎可横竖跳过河，河里有任意一方的鼠就跳不过去（鳄鱼不挡）。
进入对方陷阱战力归零，走出恢复；己方陷阱对己方无效。
不得进入己方兽穴，进入对方兽穴即获胜；吃光对方或对方无子可动也算赢。

## 五档难度

| 难度 | 最大深度 | 实测完成 | 思考时间 | 静态搜索 | 置换表 | 空着裁剪 |
|---|---|---|---|---|---|---|
| 1 最简单 | — | — | 10ms | — | — | — |
| 2 有点难 | 2 | 2 层 | 80ms | — | — | — |
| 3 很难 | 4 | 4 层 | 400ms | 2 层 | 有 | — |
| 4 非常难 | 6 | 6 层 | 1.2s | 4 层 | 有 | — |
| 5 最厉害 | 8 | 7–8 层 | 3s | 6 层 | 有 | 有 |

「最大深度」是上限，实际搜多深由时间决定——迭代加深，算完一层才用这一层的结果。
所以慢一点的电脑上高档会自动搜浅一些，不会卡死，只是稍弱。上面的实测值是在这台 iMac 上量的。

难度 1 不是纯随机：它会优先吃子，也会避开一步就被白吃的走法。
六岁孩子跟纯随机对手下没有成就感。

强度不是只靠堆深度。三档以上开了**静态搜索**（把吃子序列算到平静为止）——
没有它，搜索可能正好停在兑子中途，把亏本买卖看成划算的，深度越大误判越离谱。
五档另外开了**空着裁剪**，同样 3 秒能多搜一层。

难度 4、5 每步真要想零点几到三秒，页面在这期间是卡住的，界面会显示「电脑在认真想…要等一下」。
时间上限锁死 3 秒，再久孩子就不等了。

连输两盘自动降一档，连赢两盘会问要不要升档，最高到 5。

### 为什么深度是 2 / 4 / 6 / 8，不是 2 / 3 / 4 / 5

**全用偶数是刻意的。** 搜索深度为奇数时，最后一层是自己走的，评估会系统性高估局面，
下法变得更凶。配上这个偏保守的评估函数，实测**深度 3 反而以 3:0 打赢了深度 4**。
奇偶混用会让「加一层就更强」不成立，所以五档全部落在偶数深度上，绕开这件事。

### 实测阶梯

相邻两档对弈，交换先后手，**固定搜索深度**。关键指标是 0 负——平局多半是步数上限，
不是势均力敌。

用时钟跑这个测试是不可复现的：机器忙一点，各档搜到的深度就变，同一个随机种子也能翻盘
（实际发生过——同一份代码先跑全过、再跑就挂）。棋力的本质是深度，所以按深度测。

L5 对 L4 无法用同样方式证明：那需要深度 8 对 6 且不设时限，每步要算好几分钟。
L5 买到的东西是空着裁剪，所以改验证一件等价且能确定测的事——**它到达同样深度花的时间更少**，
这正是它能在同样 3 秒里多搜一两层的原因。

这套测试在 `test/ai.test.js` 里，跑一次要几分钟。

### 为什么要防重复

两个引擎都无利可图时会把同一个子来回走，直到步数耗尽。所以对局会记住最近 8 个局面，
AI 走回老局面要扣一点分——分值很小，绝不会让它放弃真正的吃子或获胜走法，但足以打破干耗。

## 看清电脑走了哪一步

电脑落子太快，孩子常常没看见。所以每次电脑走完，棋盘上会留下一整套痕迹：

| 元素 | 作用 |
|---|---|
| 棋子从起点**滑**到终点（340ms） | 看见"它在动"，最直接 |
| 起点留**蓝色虚线圆** | 没看到滑动也知道从哪来 |
| 终点套**蓝色虚线框** | 知道落在哪 |
| 两点之间**虚线箭头** | 一眼看完整步棋，狮虎跳河跨四格时尤其需要 |
| 被吃的子变成**红叉徽章**贴在终点格角上 | 否则孩子只看到"少了一个"，不知道被谁吃的 |
| 同归时两格各放一个**大徽章** | 两个一起消失，得让它看得见 |
| 顶栏「**刚才走的**」按钮 | 没看清可以重看，次数不限 |

痕迹用蓝色（电脑方的颜色），不会和你自己选中棋子的金色混淆。

**痕迹留到你走下一步为止，不倒计时消失。** 六岁孩子可能正看着别处，
定时消失会让他错过——他不该为了看清楚而赶时间。

只标电脑的走法。你自己走的不标：你知道自己刚做了什么，标出来只是视觉噪音。

| 你的棋子 | 奶油牌 + 绿边框、绿名字 | |

**棋子不涂成纯绿纯红，保持奶油底加彩色边框。** 绿棋子放在绿草地上会失去轮廓，
实体棋盘也是这么处理的。

菜单沿用同一套语言：教学关是绿的（在你自己这边学），对局是红的（去打红方）。

## 针对 6 岁做的交互决定

| 项 | 取值 | 为什么 |
|---|---|---|
| 操作方式 | 点选，不是拖拽 | 6 岁用鼠标拖拽容易中途松手，失败了还没有反馈 |
| 棋格大小 | 88px，最小 52px | 随窗口自适应，小于 52px 开始点错 |
| 棋子字号 | 格子的 48% | 认得字，所以用汉字不用图标 |
| 选中反馈 | 放大 1.09 + 金色描边 | |
| 合法落点 | 绿色圆点；能吃的画红圈 | 不用记规则，看得见就行 |
| 走错 | 棋子左右抖动 + 语音说明 | 不弹窗，不打断 |
| 走进对方陷阱 | 自动退回一步 + 语音解释 | 这一步合法但是坏棋，是教学重点 |
| 悔棋 | 每局 3 次 | 够改一次误点，不够反复试错 |
| 单局时长 | 不强制，超过 15 分钟提醒休息 | |
| 难度调整 | 连输 2 局自动降一档；连赢 2 局问要不要升 | 不用大人干预 |
| 进度 | 存在浏览器里，换电脑不同步 | |
